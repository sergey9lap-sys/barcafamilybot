# Проверка бота и Mini App

Проверено 9 сентября 2026 года на изолированных данных. Реальные голоса не изменялись.

## Результат

- 29 автоматических тестов прошли: сохранение и изменение голосов, конкурентные записи, запрет дублей, подсчёт сезона, сроки голосования, роли администратора, Telegram-подписи, webhook и обработка ошибок.
- 7 сценариев фильтров в браузере × 3 ширины (390, 768, 1440) = 21 успешная проверка: високосный февраль, месячный запрос зрителей, сохранение неприменённого выбора при автообновлении, понятная ошибка сервера, повторная загрузка, период около полуночи в Москве, неправильный диапазон дат.
- Проверены в локальном макете голосование, рейтинги игроков и зрителей, история, редактирование состава на телефоне, планшете и компьютере. Ошибок JavaScript не обнаружено.

## Исправления

1. Автообновление рейтинга больше не сбрасывает неприменённые изменения фильтров после потери фокуса.
2. Последние 30/90 дней используют календарную дату устройства, без сдвига на предыдущий день при преобразовании в UTC.

## Повторный запуск

`node --test --test-concurrency=1 test/*.test.mjs`

`node scripts/test-community.mjs`

Для браузерной проверки нужны Chrome и Playwright. По умолчанию используется установленный runtime рабочего окружения; на другом компьютере переменная `PLAYWRIGHT_PACKAGE` должна указывать на абсолютный путь package.json пакета, откуда доступен Playwright. Тест самостоятельно подменяет ответы API и не требует работающего сервера.

## Границы проверки

Это функциональные проверки, не нагрузочный тест и не полный аудит безопасности. Реальные Telegram, Supabase, Vercel и будущий Go-бэкенд этой проверкой не охвачены. Новые рейтинги и история проверены с тестовыми ответами API; после подключения бэкенда требуется сквозная проверка реального подсчёта. Размеры браузерного окна не заменяют проверку на физических устройствах.
