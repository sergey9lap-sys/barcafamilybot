# Barca Family

Тестовый Telegram-бот и мини-приложение для оценок игроков после матчей.

## Текущая версия

- Бот: https://t.me/barcafamilyratingbot. Кнопки 1–5, отдельный официальный портрет каждого игрока, изменение оценок, результат команды и игроков.
- Локальное приложение: http://127.0.0.1:3188. Пока доступно на этом компьютере, внутри Telegram ещё не опубликовано.
- Админка: создание матча, выбор состава, открытие и закрытие голосования, управление доступами владельцем.
- Редактор сообщений и кнопок: `/admin` → «Тексты и эмодзи» / «Названия кнопок». Готовый текст отправляется обычным сообщением, сохраняются форматирование и идентификаторы премиум-эмодзи. Перед публикацией есть предпросмотр. В кнопке Telegram поддерживает один премиум-значок перед текстом.
- Клубный список из 27 игроков и официальные портреты проверены 07.09.2026. Ушедшие игроки скрыты из выбора нового состава, старые оценки остаются в истории.
- `demo-valencia-v2` — новая демонстрационная анкета из актуального клубного списка. Она не является заверенным протоколом участников матча и не учитывается в настоящем сезоне. Старую тестовую анкету закрыли без удаления её голосов.

## Запуск после перезагрузки

Запустить `Запустить Barca Family.ps1` из папки проекта. Скрипт запускает бота и приложение в фоне; при аварийном завершении процесс перезапускается. Компьютер должен быть включён и подключён к сети. Автозапуск при входе в Windows не установлен. Это не круглосуточный хостинг.

Нужен Node.js 24+, зависимости устанавливаются через `pnpm install --frozen-lockfile`. Настройки находятся в `.env`; этот файл исключён из Git. Никогда не публиковать токен, `.env` или папку `data`.

Первый владелец не назначается автоматически. Пользователь отправляет `/whoami`, затем оператор запускает `pnpm owner ЧИСЛОВОЙ_ID`. В дальнейшем владелец может выдать/отозвать права и передать владение через админку. Владелец в базе проекта и владелец бота в BotFather — разные роли; передача первой не передаёт вторую.

## Премиум-эмодзи

Telegram разрешает custom emoji в прямых сообщениях ботов, если владелец бота в BotFather имеет Telegram Premium, либо выполнено условие Telegram с дополнительным именем на Fragment. Premium у администратора проекта сам по себе этого не гарантирует. Если Telegram явно отклоняет custom emoji, бот повторяет отправку с обычными эмодзи, а оригинальный текст хранится в базе. Отображение конкретного набора нужно проверить в предпросмотре в Telegram.

Официальные правила: https://core.telegram.org/bots/api#formatting-options и https://core.telegram.org/bots/api#inlinekeyboardbutton.

## Хранение и расчёт

Локальная база: SQLite в `data/barca.sqlite`, режим WAL. Для публичного запуска предусмотрено подключение PostgreSQL через `DATABASE_URL`; Supabase также предоставляет PostgreSQL. Схема создаётся сервером. Производственный запуск с `NODE_ENV=production` требует PostgreSQL, токен и `PUBLIC_URL=https://…`; demo-режим на публичном интерфейсе запрещён. Для production нужна отдельная база без демонстрационных матчей.

Ключ оценки: матч + Telegram ID + игрок. Версии анкеты защищают от перезаписи из другого окна/бота. Черновики не учитываются в результате до отправки. Правки отправленной анкеты влияют на предварительный результат до закрытия матча. Состав фиксируется при открытии.

Игрок за матч: среднее полученных оценок. Команда: среднее оценок игроков, отсутствующие оценки не равны нулю. Сезон: среднее итоговых оценок за закрытые настоящие матчи, каждый матч с одинаковым весом. Кеш результатов — до 10 секунд.

## Перед публичным запуском

Подключить сервер и PostgreSQL, настроить HTTPS и `PUBLIC_URL`, перевыпустить опубликованный в переписке токен, назначить владельца, проверить фактический состав матча. Повторно запустить `scripts/connect-bot.mjs`: меню приложения будет на русском. Нужны резервные копии с проверкой восстановления, мониторинг ошибок и проверка нагрузки на выбранном сервере. Один экземпляр Telegram poller; сервер API можно развивать отдельно.

Ориентир для испытаний: VPS 4 vCPU / 8 ГБ RAM / 60–80 ГБ SSD. Это не гарантия вместимости. Обычный разделяемый хостинг сайта не подходит для выбранного запуска постоянных процессов. Supabase — опция управляемой PostgreSQL, а не отдельный тип базы.

## Проверки

`pnpm test`: хранение, авторизация, конкурентные голоса, роли, итоги сезона, очередь фонового сохранения, редактор rich text и смена фотографий в API бота.

`pnpm load-test 1000`: изолированная локальная проверка SQLite, 1000 анкет по 16 оценок, 50 параллельных исполнителей. Не проверяет Telegram, сеть, PostgreSQL или будущий VPS.

`scripts/browser-check.mjs`: проверки интерфейса через Playwright. `PLAYWRIGHT_PACKAGE_ROOT` указывает папку с установленным пакетом playwright.
