# Портреты игроков

28 фотографий вырезаны из предоставленных владельцем листов `1.jpg`–`7.jpg`. Привязка имён и порядок на листах заданы владельцем. Жёлтые рамки сохранены; размер каждого файла — 410 × 410.

Полная привязка, координаты обрезки и пути: `portrait-replacements.json`.

Для 26 игроков сохранены прежние имена файлов в `public/portraits`, включая расширения PNG. Эти пути используются Mini App и ботом. После выпуска ветки новые сообщения и карточки используют новые изображения; уже отправленные сообщения автоматически не переписываются. Бот вычисляет ключ кеша Telegram по содержимому файла.

- Ориен Горен: `/portraits/goren.jpg`.
