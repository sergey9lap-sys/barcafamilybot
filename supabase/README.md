# Подключение Supabase

1. Создай отдельный проект для бота. В SQL Editor вставь весь setup.sql и нажми Run.
2. Скрипт создаёт 12 таблиц, индексы, состав и владельца 676858855. Повторный запуск сохраняет существующие данные.
3. Таблицы закрыты для публичного API. Доступ идёт через сервер бота с проверкой Telegram.
4. Connect → Transaction pooler → скопируй URI (порт 6543). Это DATABASE_URL; пароль кодируется как часть URL. Сохраняй его только в .env или секретах Vercel.
5. Не добавляй DATABASE_URL и BOT_TOKEN в GitHub. Публичный anon key для текущей архитектуры не нужен.

setup.sql не переносит локальные голоса, отредактированные тексты или матчи. Их перенос выполняется отдельно после подключения. Скрипт проверен на соответствие схеме приложения; выполнение в облачной PostgreSQL ещё предстоит.

Текущий код запускается постоянным процессом. Перед деплоем Vercel требуется отдельный webhook-обработчик; импорт репозитория сам по себе ещё не запускает бота.
